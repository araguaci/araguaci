# Código de conduta

Este repositório é o perfil público de Araguaci. Discussões, issues e pull requests seguem o mesmo critério: respeito à pessoa, mesmo quando o tema é duro.

## O que se espera

- Critique o argumento, o link ou o dado. Não ataque a pessoa.
- Não publique dado pessoal de terceiros, endereço, documento ou conteúdo íntimo.
- Não use este espaço para spam, golpe ou assédio.
- Se discordar de um projeto listado, aponte a fonte. Hipótese não vira fato sem prova.

## Onde vale

Vale para issues, pull requests, comentários e qualquer canal ligado a este repositório.

## Como reportar

Escreva para [araguaci@gmail.com](mailto:araguaci@gmail.com). Descreva o que aconteceu, onde, e quando. Mensagens de boa-fé são lidas. Quem insistir em assédio ou spam perde o espaço de comentar.
