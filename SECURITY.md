# Segurança

Este repositório é um perfil e um catálogo de links. Não há aplicação servindo dados de usuários aqui.

## O que reportar

- Segredo, token ou credencial commitado por engano.
- Link do README que passou a apontar para um site que se passa por um projeto meu.
- Workflow do GitHub Actions com permissão maior do que a necessária.

## Como reportar

Escreva para [araguaci@gmail.com](mailto:araguaci@gmail.com). Não abra issue pública com o segredo dentro. Diga o arquivo, o commit e o que você encontrou, sem colar o valor do token.

## O que este perfil não cobre

Vulnerabilidade dentro de um projeto listado (por exemplo `lawfare-timeline` ou `sabor-brazil`) deve ser reportada naquele repositório, não aqui.
